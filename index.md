# Allodium Documentation

Allodium is a data platform you run in your own cloud: the control plane
orchestrates workspaces, catalogs, and governance, while your data and compute
stay inside your account. This is the home for everything you need to deploy,
operate, and govern it.

## Where to start

- **[Getting Started](/docs/getting-started)** — install the agent, connect a
  data plane, and provision your first workspace.
- **[Architecture Guide](/docs/architecture-guide)** — how the control plane,
  data plane, and ingestion paths fit together.
- **[API Reference](/docs/api-reference)** — authentication and the
  workspaces API for programmatic access.
- **[Governance & Security](/docs/governance-and-security)** — identity,
  access control, and audit logging.
